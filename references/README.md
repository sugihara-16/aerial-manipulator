# 本家の参照資料

本家の機体条件とこれまでの知見を、独立した作業場所で確認するためのコピーです。

[コピー台帳](mainline_snapshot.json)には、各ファイルの元のパス、コピー先、サイズ、SHA-256を記録しています。本家は別作業で更新されるため、参照している版はこの台帳のバイト列で識別します。資料内の相対リンクには、本家の成果物を指し、このコピーには含まれないものがあります。

機体URDFとメッシュは `../assets/robots/holon/`、物理設定は `../configs/robot/` にコピーしています。URDFが参照する `mesh/` をこのリポジトリ内で解決できるよう、メッシュも通常のファイルとして保存しています。

設計仕様・制御仕様・接触領域の検証記録・VIM4測定記録は歴史資料です。現行の手法は [DETERMINISTIC_METHOD.md](../for_codex/DETERMINISTIC_METHOD.md) です。特に本家の学習工程、制御器の変数制限、①〜⑤の工程番号を、このサブプランの要件として適用しません。物理限界や観測条件を変更してよいという意味ではありません。
