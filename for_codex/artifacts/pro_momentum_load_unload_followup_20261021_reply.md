**その分け方でよいです。分岐条件は形状名ではなく、「外側の加速度補正をゼロにした基準保持が、現在の実状態で成立するか」です。**

円柱・箱は、把持を維持できる負荷範囲から経路進行を決める方向へ進めます。三角柱はその前段階で、**現在の相対形状と実指令が整合する保持状態を作り、実際にそこへ移してから支持を離す必要があります。**

また、世界原点周りへ移して力積と比較しているとの補足により、前回答の移動原点項に関する確認事項は解消しています。

## 1. 今回の対照からの判断

### 円柱・箱：負荷範囲から経路進行を制限する根拠がある

同じ15秒で、無負荷・1/4負荷は入力制限なしで通過し、全負荷では入力制限と大きな材料点移動を伴って破綻しています。さらに、同じ12秒間の比較でも低速搬送だけが通過しています。

これは、**現在の内部保持が受け持てる負荷範囲が存在し、その範囲へ外側要求を収める方針**を支持します。1/4という係数を採用するのではなく、基準保持入力、外側補正、実際の関節位置・速度誤差を合成した指令の許容域から進行を決めるべきです。

入力制限が破綻の最初の原因だったかは、まだ確定していません。また、入力が定格内なら把持も保たれるという十分条件も得られていません。今回の有限負荷試験で確認した内部変位の範囲を併用する必要があります。

### 三角柱：経路進行を調整する前に、基準保持を修正する

外側補正なしでも要求トルクが \(-1.44192\,\mathrm{Nm}\) となるため、加速度を下げてもこの入力超過は消えません。物体姿勢誤差が小さくても、関節角差と \(K_p\) によって約 \(0.158\,\mathrm{Nm}\) が加わる関係は、直接説明できています。

さらに、現在姿勢の静的問題が負担3.840で不成立です。したがって、少なくとも現生成モデルでは、**同じ姿勢のまま入力だけを選び直せば保持できるとは置けません。相対形状も生成変数に入れる必要があります。**

同じ実トルクを別のMIT指令で表現し直しても、力学的作用は変わりません。位置誤差項を消してトルクを下げるなら、それは保持作用の変更なので、接触との釣合いを再確認する必要があります。

## 2. 提案する最小構成

提案は、**把持の相対状態を観測して、実入力に適合する近傍の保持目標を生成・修正し、既存の関節制御でそこへ近づける構成**です。

新たな全状態帰還を作るのではなく、現在の静的生成と実サーボの間に欠けている関係を、同じ局所問題で扱います。

### ① 把持を表す観測量を固定する

制御目標には、次を使います。

- 各パッドの法線変形。
- 物体とパッドの材料点の接線変位・速度。
- 保持に関係する相対関節姿勢。

法線変形は、必要荷重と上限に対応する**許容帯**を目標にできます。材料点の対応は保持目標の生成時に定め、その後の累積変位を残します。毎周期、現在位置を新しいゼロへ置き換えると、滑りを再び制御目的から消してしまいます。

制御目的をこれらの量へ絞っても、力学計算と実入力の検査には観測q/vをそのまま使います。

### ② 近傍の相対形状と実指令を同時に生成する

現在状態の近傍で、**小さな相対変形、低速の目標運動、実ローター・MIT指令**を未知数にします。物理条件を満たす中で、現在からの変形と指令変更を小さくする問題です。

最低限、全機体と物体について、

\[
M(\hat q)\hat a+h(\hat q,\hat v)
=
Q_{\mathrm{act}}(\hat q,\hat v,c)
+J_c^\top\lambda_c
+J_s^\top\lambda_s
\]

を満たします。ここで \(\hat q,\hat v\) は生成する近傍の目標状態、\(c\) は実指令、\(\lambda_c,\lambda_s\) は把持接触と支持接触の反力です。保持点では加速度をゼロ、または必要な小さい共通加速度として扱います。

この式に、次の条件を一体で入れます。

- **反力と変形・滑りの適合。** 現在採用している有限法線則・摩擦則の局所モデルを使う。摩擦円錐内の反力を自由に選んで終わらせない。
- **実駆動への適合。** 正推力、現在のgimbal方向、MITの位置・速度項と補助入力の合成、各上限を含める。
- **接触と形状の適合。** 必要な小変形が、パッド範囲、材料点変位、関節範囲、衝突距離を満たす。
- **空中保持の成立。** 引渡し先の保持点では支持反力を使わない。そこへ移る区間では実際の支持接触を含める。

接触力の存在と、その指令・変形から接触力が生じることは別です。この区別は、受動的な把持能力を評価する際にも必要とされています。[arxiv.org](https://arxiv.org/html/1801.06558v1?utm_source=chatgpt.com)

物体の運動方程式には、直接の駆動入力を置きません。物体への作用は接触を通して生じるものとして解きます。したがって、把持座標への仮想的な復元力を、そのまま実モータ入力へ割り当てたことにはしません。また、\(T^\top B\delta u=0\) だけで任意の内部変形を作れるとも置きません。

**今回の三角柱では、この生成を支持が残る段階で行うのが最小の入口構成です。** 現在の不整合を持ったCARRY状態から、空中で安全に回復できる根拠はまだありません。

### ③ 観測誤差から目標を修正し、合成後の実入力を制約する

生成した保持目標に対して、観測された法線変形・材料点変位が許容帯から外れれば、帯へ戻す低速の目標変化を要求します。その要求を、**②と同じ局所釣合い・実入力制約へ通してから**、関節目標とローター・MIT指令として発行します。

これが内部保持の帰還です。必要なのは幾何関係と既知の駆動則であり、全状態の接触応答を数値微分したA/Bではありません。毎周期の精密MuJoCo予測も要求しません。

MITについては、必ず

\[
\tau_{\mathrm{req},j}
=
K_{p,j}(q_{d,j}-q_j)
+K_{d,j}(v_{d,j}-v_j)
+\tau_{\mathrm{ff},j}
\]

を**発行時の観測q/vで評価**します。生成目標 \(\hat q\) におけるトルクが定格内というだけでは足りません。目標への誤差が作るトルク、内部補正、予定する外側補正を合成した上で入力余裕を残します。

ここで要求トルクまで定格内に置くのは、位置・速度帰還の作用を予定外の飽和で変えないための制御設計条件です。物理上限を変更する話ではありません。

旧位置指令へ補助トルクを単純加算するのではなく、**実現したい合成トルクと位置・速度目標を同時に決める**ことで、今回の約0.158Nmを計算から落とすことを防ぎます。

## 3. 入口条件は「姿勢一致率」ではなく実現性にする

支持離脱への引渡しには、次を同じ観測状態で確認します。

1. 支持反力なしの保持目標が、接触則と実駆動に適合して生成されている。
2. 現在q/vを代入したMIT合成入力と推力に、必要な補正余裕がある。
3. 法線変形、材料点変位・速度、関節状態が、生成した保持の許容帯に入っている。
4. 目標への移行中も、入力と接触の条件が保たれている。

「予圧と低接線速度が0.3秒続く」という判定は、3の一部として残せます。しかし、1と2の代わりにはなりません。

この構成で説明できるのは、**観測した内部状態、有限接触の局所モデル、実際の入力作用を整合させる関係**です。近傍の釣合いが解けただけで、そこへ安全に到達できることや、15秒保持できることまでは保証しません。目標状態の成立を、次周期や区間全体の成立へ読み替えないことが必要です。

## 4. 次の採否試験は一つ

**同じ三角柱の支持離脱前の保存状態から、「保持目標の生成 → 実際の相対形状の修正 → 荷重移行 → 15秒の無加速度空中保持」を、状態を置き換えず一続きに実行する試験**に絞ります。計算待ち中も制御と物理時間を進めます。

合否は、移行区間を含む全物理監査、発行時の合成入力余裕、物体の位置姿勢、材料点変位・速度で決めます。接触力真値は監査だけに使います。

- **近傍保持目標が生成できない場合**：この入口からの局所的な引渡しは未成立です。同じ姿勢で自由な反力を選び直して採用しません。
- **目標は生成できても、移行または無加速度保持で破綻する場合**：局所生成と実応答の接続が未成立です。経路時間の問題へ戻しません。
- **一続きに通過する場合**：今回の基準不整合を、個別クリップや姿勢一致率によらず解消した根拠になります。その共通規則を円柱・箱にも適用し、退行を含む共通評価へ進めます。

今回の数値は、この内部目標と実入力の整合を優先する十分な理由です。近傍に実行可能な保持状態が必ずあることまで示してはいません。まずそこを同じ生成規則で作り、実際に到達して保持できるかを判定するのが、必要な最小の変更です。
