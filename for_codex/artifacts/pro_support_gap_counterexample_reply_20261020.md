**前回答の「支持関数の不等式へ置き換える」提案は、今回の誤接触を排除するには不十分でした。必要なのは、先にEPA自身の方向と深さを検査し、合格したEPA方向へ多点候補を投影して比較する順序です。ご提示の(a)(b)(c)を、その順序で組むのが妥当です。**

支持関数の不等式は、形状上の任意の点対に成立します。そのため、反対面との誤った対応も通します。これは距離の取り得る範囲の確認であり、接触に使う面・方向が適切だという確認ではありません。

## 1. 多点化する前に、EPAの方向と深さを照合する

形状順をA→B、単位法線を \(n_0\)、EPAの侵入量を \(\delta_0=-d_0\) とします。証人点について \(a_0-b_0\simeq\delta_0n_0\) が成立することを確認したうえで、

\[
H_0=
\max_{a\in A}n_0^\top a
-\min_{b\in B}n_0^\top b
\]

を計算し、**事前に決めた長さ単位の数値許容**で、

\[
\boxed{
-\varepsilon_{\rm round}
\le H_0-\delta_0
\le \varepsilon_{\rm EPA}
}
\]

を要求します。

これは「Bをその方向へ \(\delta_0+\varepsilon_{\rm EPA}\) 動かせば、支持面で分離できる」という整合確認です。この条件だけで、全方向中の最小並進距離を証明するわけではありません。

今回の上向き法線では、

\[
H_0-\delta_0
=0.737331081-6.063\times10^{-10}
\simeq0.7373310804\ {\rm m}.
\]

したがって、**319mmの候補を調べる前に、このEPA結果からの多点化を確実に拒否できます。**

重要なのは、**観測された大きな \(H_0-\delta_0\) を、そのまま多点側の許容へ加えないこと**です。それをすると、前回答の弱い不等式へ戻ってしまいます。

## 2. 合格したEPA方向へ、実際の候補点対を投影する

多点候補の法線 \(n_i\) には、既存の向き・整列条件を課します。

\[
n_i^\top n_0\ge\cos\theta_{\max}.
\]

そのうえで、生成処理が実際に使った点対 \(a_i,b_i\) に対して、

\[
\boxed{
n_0^\top(a_i-b_i)
\le
\delta_0+\varepsilon_{\rm EPA}+\varepsilon_{\rm geom}
}
\]

を検査します。報告距離も \(d_i\simeq n_i^\top(b_i-a_i)\) と整合している必要があります。形状順とmarginの扱いは全計算で統一します。

**有限角度差は、この直接投影で扱えます。** 点対が \(a_i-b_i=(-d_i)n_i\) を満たす場合に限り、左辺を \((-d_i)\cos\theta_i\) と書けます。接線方向の点差がある場合は、それも含む実際の点対を投影してください。

面・辺への所属と、形状順に対して正しい側を向いていることも必要です。ただし、**多点の全点を厳密なEPA支持平面上に要求すると、わずかに傾いた正しい面まで落とします。** 支持特徴の向き・所属の検査と、上の深さ検査は分けます。

## 3. 数値精度付近では、未確定な法線を拡大しない

深さが数値許容帯にある、または1の整合確認に不合格なら、多点化しません。必要なら、**回数と精度を事前固定した単接触の再計算**を行い、再計算結果にも同じ入口検査を適用します。

今回、元の単接触も上向きだったので、拡張を捨てただけでは「正しい単接触に戻った」とは言えません。精密再計算後の整合した単接触を使い、それでも未確定なら数値未確定として記録する必要があります。法線が非一意な接触もあるため、新旧法線の完全一致を一般条件にはせず、支持面との整合で判定します。

この構成なら、**今回の不確かなEPA方向が319mmへ増幅される経路を止め、有限角度差も幾何として扱えます。** 物理的な力や2mmの監査閾値を判定に持ち込む必要はありません。既存の広い形状照合は維持し、この数値精度付近の保存姿勢を入口判定の回帰例に加える範囲で十分です。
