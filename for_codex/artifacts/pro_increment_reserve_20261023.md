# 増分配分とタスク修正能力の追加レビュー

相談先: https://chatgpt.com/c/6ad7c38d-aeac-83eb-bf56-e58882046c27
画面記録: `pro_increment_reserve_20261023.png`。以下は2回答の要約であり引用ではない。

- 名目サーボが作る加速度を打ち消さず、入力増分が作る加速度を目的にする変更は整合する。入力増分、基準加速度、全体作用の等式は同じ名目入力を基準にする。
- 100Hzとゲインの値だけでは失敗原因を断定できない。実際の閉ループ動作を比較する。
- 位置・姿勢・運動量から作る誤差の正規化L1和<=1を、制御開始時の設計条件として明示する案は可能。以前から使う費用尺度が、その条件の成立を保証するわけではない。
- 名目加減速と許容誤差による修正要求の全組合せを、同じ姿勢・実gimbal角・重心・制御則で検査する。凸性による頂点検査が保証するのは、その固定された線形推力集合への包含だけ。
- 姿勢を修正したら、接触モデルと制御則を再計算する。実gimbal角の移行、内部相対運動、支持離脱、全工程成功は別途検証が必要。
- 接触点数や台数の一律下限を設けず、要求への対応能力を生成へ反映し、成立候補を推力負担で比較する。
- 制御ゲインを弱めて必要能力を小さくしただけでは、有効性は示せない。時間・停止・タスク条件を同時に守ることが必要。
