**1µmの単点screenを採用条件にはしない、という判断を支持します。次の最小変更は、静的な点集合や採点をさらに変えることではなく、現在の静的順位に「現制御で実タスクの取得からCARRY終端まで通るか」という検査を一つ加えることです。**

ただし、**別の静止保持試験を新たな必須条件にすることは勧めません。** 既存の運搬軌道と終端保持を使えば、その候補が本来遂行すべき区間を直接検査できます。計算費用は増えるため、まず選択法の開発比較として位置付けます。

## 1. 幾何だけでは、今回欠けている条件を補えない

現行LPで示しているのは、選んだ材料点について、

\[
G(q)\lambda=w_{\rm required},\qquad
\lambda_i\in\text{摩擦錐}
\]

を満たす力の組が存在することです。一方、実行中の力は、同じパッドの変形・相対運動・位置指令・駆動応答によって結び付いており、各点へ独立に割り当てられません。**同じ一組の姿勢と入力から、その力分布が生じるという条件がLPにはありません。**

200µm帯を1µmへ狭めると、この自由度を減らせます。しかし、成功した円柱も落ちるという今回の結果は、有限面が実際に役立つ候補まで除外することを示しています。逆に、単点でも静的に成立する楕円の失敗が残るので、この操作だけで実現性を判定することもできません。

したがって、今回の資料からは、**どの幾何帯幅なら実荷重を適切に代表するかは決まりません。** 幾何検査は候補の成立範囲や弱い回転方向の説明に残し、現駆動での荷重実現を認定する役割までは持たせないのが適切です。

## 2. 一つに固定する比較：静的順位順に、実CARRY終端まで予測する

候補集合は現行の「最初の静的合格2個」、順位も現在の最大モータ使用率のままにします。新しい荷重・接触数・モータ平均値のスコアは加えません。

**静的順位1位から、次の区間を一度だけ独立モデルで実行します。**

> 完成体スポーン → APPROACH → ACQUIRE → LOAD → PROBE → LIFT → **元のCARRY軌道の終端・既定の終端保持まで**

途中の違反または既存の段階期限で打ち切り、CARRY終端を通れば予測を終了します。PLACE／UNLOAD／RELEASEは、この候補選別用の予測には含めません。

実装上は、以下をそのまま維持します。

- 同じ初期条件、共通制御、接触物性、比較用エンジン版。CARRYの追加閉じ速度は0。
- 物理状態、制御参照、前指令を連続して更新。監査履歴は既存の段階切替規則どおりに扱う。
- 全物理監査、各段階の終了条件・期限、CARRYの各pad **0.5N／0.05秒**条件。
- 計画法線力への一致、全軸無飽和、接触点数の維持などを新しい合格条件にしない。

選択規則も一つです。

| 予測結果 | 選択 |
|---|---|
| 静的順位1位が通過 | その候補を採用し、2位の予測は省略 |
| 1位が不合格、2位が通過 | 2位へ変更 |
| 両方不合格 | この2候補・現制御では未選定 |
| 計算未完了・数値未解決 | 物理的不成立と分けて未判定 |

これなら、予測を追加したことで**候補の選択が実際に変わります**。単に評価項目を増やすだけではありません。

### なぜ短い静止保持ではなく、元のCARRY終端か

以前の「CARRY最初2秒」の負担順位は後段の成否を識別できませんでした。また、持上げ後に別の静止課題を追加すると、運搬では成立する候補を、その反事実の保持で落とす可能性があります。

元のCARRY終端を停止点にすれば、窓を失敗時刻に合わせて延長せず、**もともと要求されている運搬時間・運動・終端条件**で判定できます。これは6方向の復元能力全体の認定ではありませんが、その入力・候補・共通制御で接触を実現し、必要な運搬区間を維持できたかは直接検査できます。

## 3. 実行前に、選択を変え得るかだけ既存記録で確認する

今回3接触で救えた候補が、元の「最初の2候補」のどちらかと同一かを照合してください。別の種・姿勢から生成された候補なら、**その成功は探索範囲の改善例であり、現在の2候補間の選別で再現できる証拠ではありません。**

併せて、現在の選択候補が既にCARRY終端まで通っている条件では、この規則は選択を変えません。残る失敗がすべてそれに該当するなら、追加予測を走らせる前に、今回の選別案には効果がないと判断できます。

同版・同初期条件・同候補の既存全工程記録でこの区間が確認できる場合、開発比較のために同じ区間を再実行する必要はありません。ただし、将来の新規入力で必要になる予測費用とは区別して記録します。

## 4. 採否と費用の範囲

この検査を通っても、**PLACE／RELEASEの成立や未知外乱への余裕は分かりません。** 選択した1候補だけを全工程評価し、共通48条件で成功転換・退行・形状別結果を比較します。失敗6例の救済だけを選別性能にはしません。

棄却条件は、事前に次のように固定できます。

- 旧選択候補も検査を通り、選択が変わらないなら、その失敗への効果はない。
- 選択は変わっても全工程の改善や偏りの縮小が得られなければ、この選別法を採用しない。
- その場合に、保持窓・荷重順位・候補数を後付けで変更して同じ比較を延命しない。

費用は**最大2本の取得～CARRY終端予測**です。既存の取得を含む予測費用から、15秒程度の生成・選択要件を満たすとは現時点で言えません。順位1位が通った時点で2位を省略することが、選択結果を変えずに削減できる部分です。生成・失敗した予測・全監査を含む費用を計上し、選択の有効性と実行費用を別々に判定してください。

今回追加する対象は、**自由な有限面力の静的解を、現行制御で実現できる候補と同一視しないための、実タスク区間による選別**です。新しい平衡点探索や制御器を作る必要はありません。
